# 🔫 GEARZ Payload Smith

**GEARZ Payload Smith** is an AI-powered payload generator built for bug bounty hunters, red teamers, and cyber outlaws.  
Describe a vulnerability — and the Smith forges payloads instantly. Works with **Ollama (LLaMA3)** or the **OpenAI API**.

---

## ⚙️ Features

- 🎯 AI-generated payloads with Beginner / Advanced toggle
- 💾 Save-to-file output for reuse
- 🖥 Terminal-inspired hacker UI
- 🔁 Works offline via Ollama or online via OpenAI
- 🛠 Built with Next.js App Router + Tailwind CSS
